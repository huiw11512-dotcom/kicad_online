# A1载板结构

## 1. 计算模块

Raspberry Pi CM5，候选料号CM5104032（4GB RAM、32GB eMMC、Wi-Fi/BT）。模块尺寸约55 × 40 mm，通过两个100-pin连接器安装在载板上。

## 2. 首版接口布局

| 板边 | 接口 |
|---|---|
| 后侧I/O | 1 × HDMI 2.0、1 × RJ45 Gigabit Ethernet |
| 前侧I/O | 2 × USB 3.0 Type-A、1 × USB-C 5V/5A输入 |
| 侧边 | 1 × USB 2.0下载/维护接口 |
| 板内 | 1 × M.2 M-Key 2230 NVMe |
| 板内/边缘 | UART测试点、Power Button、nRPIBOOT、Fan接口 |

只保留必要接口。首版不做双HDMI、MIPI、PoE、40-pin GPIO、音频Codec和microSD。

## 3. 布局原则

- CM5模块靠近板中心或边缘，确保连接器下方和安装孔可达。
- M.2 2230沿板边布置，预留SSD固定孔与散热高度。
- HDMI、USB3、PCIe和Ethernet磁性接口尽量靠近对应板边，减少高速走线长度。
- USB-C电源入口靠近5V主电源路径，避免大电流绕行。
- CM5无线天线一侧朝向塑料外壳开口，保留数据手册规定的净空；若金属壳无法满足，改用模块外置天线接口。
- SoC散热器上方预留高度，风扇气流不能被接口或外壳挡住。

## 4. 尺寸与层数

- 外形初始目标约100 × 70 mm，不是冻结尺寸。
- 4层板优先评估，必要时升级6层。
- 常规FR-4；阻抗由实际叠层和板厂场求解确定。
- 不采用10层HDI作为默认方案。
