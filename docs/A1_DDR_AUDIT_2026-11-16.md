# A1 DDR 首轮技术审计 — 2026-11-16

## 结论

Rev1 首板保留 Micron MT53E512M32D1ZW-046B WT:B，2GB、x32、单 Die、单 Rank。当前 200-ball footprint 和 67 条信号映射通过源文件级比对；发现并补入了 RK3568 DDR_RZQ H7 所需的 120Ω 电阻 R41。

**DDR 尚未达到可布板冻结条件。** 已澄清：指南中的 SD6 是 LPDDR4X 基础参考模板；rkbin 的 SD4 出现在 WDQS-capable 模板集合。当前 Micron MPN 无公开 WDQS 应用注释标记，首板按标准 non-WDQS 路径推进，但仍需取得 Rockchip/FAE 的 SD6 模板和标准 DDR BIN 确认。

## 1. 器件基线

- MPN：Micron MT53E512M32D1ZW-046B WT:B
- 密度：16Gb = 2GB
- 组织：x32，两个 x16 通道 A/B，单 Die、单 Rank
- 封装：200-ball TFBGA ZW，10.0×14.5×1.05mm
- 供电：VDD1=1.8V、VDD2=1.1V、VDDQ=0.6V
- 额定速率 4266MT/s 不等于 RK3568 板级运行频率；最终频率由确认的 Rockchip 模板和 DDR BIN 决定。

4GB MT53E1G32D2FW-046 WT:C 在公开 Rockchip DDR AVL v3.01 转录中也列为 RK3568 T/A，但该 D2/FW 双 Die 方案不属于当前首板原理图，需独立核对 rank、球图、模板、BIN 和封装。

## 2. Rockchip 兼容性证据

公开 AVL v3.01 转录中，以下两个 Micron MPN 在 RK3568 栏均标记 T/A：

- MT53E512M32D1ZW-046B WT:B（D8FLP）
- MT53E1G32D2FW-046 WT:C（D8DVT）

T/A 表示样品测试适用状态，不代表 A1 板级 DDR Training 已通过，也不替代当前官方 AVL、应用注释或 FAE 确认。

模板与 WDQS 的关系已进一步澄清：

- RK3568 Hardware Design Guide Rev1.2 §2.1.7.5：RK3568_Template_LP4XD200P132SD6_43x28_1600MHz，作为 LPDDR4/LPDDR4X 基础参考模板候选。
- rkbin RK3568 表列出支持 WDQS 版本的模板集合，其中包含 SD4；表格明确 WDQS BIN 仅用于带 WDQS 要求的颗粒。
- 当前 2GB MPN 在公开 AVL v3.01 中没有 [35]/[36] 标记，首板按标准 non-WDQS 路径推进；仍需当前官方 AVL/FAE 确认。
- 当前 rkbin 标准 BIN 候选包括 rk3568_ddr_1560MHz_v1.26.bin、1332MHz、1056MHz 和 920MHz v1.26；1560MHz v1.26 优先评估，但不直接冻结。

必须取得 SD6 模板文件、精确 MPN 映射和标准 DDR BIN/频率确认。

## 5. 两个不可混淆的 ZQ 电阻

### DRAM 侧

- U10 ZQ0 → R40=240Ω±1% → VCC0V6_DDR（0.6V）。
- 依据 Micron Z42M datasheet Table 5 / ZQ description，以及 Rockchip Hardware Design Guide Rev1.2 §2.1.7.3。

### SoC 侧

- RK3568 DDR_RZQ ball H7 → R41=120Ω±1% → VCC_DDR_1V1（1.1V）。
- R41 选型：YAGEO RC0402FR-07120RL，0402，120Ω±1%，LCSC C114758；下单前核实实时库存。
- 依据 Rockchip Hardware Design Guide Rev1.2 §2.1.7.2。
- R41 已加入 A1_LPDDR4X_2GB.kicad_sch、A1_LPDDR4X_2GB_BOM.csv 和 SoC 球位审计状态。

R40 和 R41 服务于不同器件、不同网络和不同电压，不能互相替代。

## 7. RK3568 SoC 侧 LPDDR4X 未使用球位

按 RK3568 Datasheet Rev2.1 与 Hardware Design Guide Rev1.2 核对：

- DDR_ECC_DQ[7:0]、DDR_ECC_DQS_P/N、DDR_ECC_DM 共 11 个 ECC 球位仅用于支持 ECC 的 DDR3/DDR4 场景；LPDDR4/LPDDR4X 不使用，现已在 SoC 页标记 NC。
- P8 DDR_VREFOUT：Rockchip 指南明确 LPDDR4/LPDDR4X 不使用时悬空，现标记 NC。
- F5：该球位没有 LPDDR4 功能，现标记 NC。
- 单 Rank 不使用的 CS1n、CKE1、ODT1_CA 六个控制球继续标记 NC。
- 连同 USB OTG0、未使用 USB2 Host 和 SDMMC0_PWREN 等已有 NC，SoC 页现在为 607 个网络标签 + 29 个显式 NC 标记，合计 636 球位。

该修正避免将无用途的 ECC/VREF/F5 球位伪装成待分配网络。对应 CSV 的 Assigned_Net 已改为 NC。
