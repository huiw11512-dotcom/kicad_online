# A1 PCB叠层初始方案

## 基线
- 6层FR-4
- 板厚目标1.6mm
- 铜厚初始按板厂常规1oz评估
- 阻抗由最终叠层、介质厚度、铜厚和阻焊厚度计算
- BGA逃线和DDR布线按RK3568 Hardware Design Guide执行

## 层分配建议
| 层 | 用途 |
|---|---|
| L1 | SoC扇出、关键短线、高速接口 |
| L2 | 完整GND参考平面 |
| L3 | DDR/低速信号及局部电源 |
| L4 | 电源平面与必要信号 |
| L5 | 完整GND参考平面 |
| L6 | 外围接口和低速信号 |

具体层分配需结合Rockchip模板、SoC扇出、DDR器件位置及板厂工艺调整。L2/L5不得随意切割。

## 原则
1. RK3568官方指南推荐6层PCB，A1不以4层板作为默认方案。
2. DDR区域优先遵循匹配的Rockchip模板。
3. USB3差分阻抗按90Ω目标；HDMI和RGMII按SoC/PHY及板厂指南确定。
4. 高速信号不跨地平面分割。
5. 大电流路径使用铺铜和多过孔，核算压降和温升。
6. 先由板厂给出实际叠层，再反算线宽线距。
