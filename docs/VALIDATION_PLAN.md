# 设计验证计划

## A. 原理图阶段

- SoC符号引脚数量、球位坐标、Pin Type和封装Pad逐项比对原厂PinOut。
- 所有电源球、地球、NC球和保留球按原厂规则处理。
- DDR每组DQ/DQS/CA/CK拓扑与参考设计核对。
- 电源轨逐项列出电压、容差、峰值/稳态电流、时序、PG/Reset关系。
- USB/PCIe/HDMI/GMAC检查Pinmux、PHY复用和时钟资源。
- KiCad ERC无未解释错误；所有忽略项必须登记理由。

## B. PCB阶段

- 封装焊盘、BGA坐标、1脚方向和封装高度双重核对。
- 叠层、铜厚、介质厚度、阻抗目标由板厂书面确认。
- LPDDR4X、PCIe、USB、HDMI按接口规范和原厂约束执行布线。
- 关键差分线、时钟线、DDR组进行长度/拓扑检查。
- 电源回流路径、平面分割、去耦回路和过孔电感检查。
- 热源、散热器、风扇、接口插拔和外壳空间检查。
- KiCad DRC无未解释错误；所有例外必须登记。

## C. 仿真与制造审查

- DDR拓扑与阻抗/时序约束审查。
- PCIe/USB/HDMI插损、回损、串扰评估；必要时进行场求解或通道仿真。
- PDN阻抗与瞬态负载评估。
- 热分析与最坏环境温度评估。
- Gerber、钻孔、阻抗表、钢网、BOM和坐标文件一致性检查。

## D. 首板上电与功能验证

1. 不安装SoC前检查输入电源、短路和前级电源。
2. 限流上电，测量待机电流和所有电源轨。
3. 验证PMIC时序、Reset和Power Good。
4. UART捕获Boot ROM/DDR初始化/U-Boot日志。
5. 验证DDR容量、稳定性和压力测试。
6. 验证eMMC启动和Linux系统运行。
7. 验证PCIe NVMe枚举、读写和持续负载。
8. 验证USB各端口速率与热插拔。
9. 验证HDMI显示、千兆网络吞吐。
10. 运行CPU/GPU/DDR/NVMe联合压力测试，记录功耗和温升。

ERC/DRC通过不等于SI/PI通过；SI/PI通过不等于首板功能通过。
