# 项目任务书：Linux MiniHost A1

## 1. 项目目标

自主设计一块可独立运行 ARM64 Linux 的小型计算机主板，在性能、尺寸、成本和可制造性之间取得平衡。项目成果必须是可编辑、可审查、可复现的 KiCad 原生工程，并形成完整的生产与测试资料。

## 2. 研发边界

本项目自主完成：
- 系统需求和接口定义
- SoC外围电路与电源架构
- LPDDR4X、eMMC、启动和调试电路
- PCIe/NVMe、USB、HDMI、Ethernet等接口电路
- 原理图、PCB布局布线、封装和项目规则
- SI/PI、热设计、DFM和板级验证
- Linux BSP适配、设备树和启动测试

允许使用原厂评估板、原厂参考原理图、芯片数据手册和公开软件作为设计输入，但不得把第三方PCB或原理图直接改名作为本项目成果。所有参考内容均须记录出处、版本和采用理由。

## 3. 第一版验收目标

P0：
1. 12V输入后各电源轨按规定时序启动。
2. UART可观察完整Boot日志。
3. DDR初始化稳定。
4. eMMC启动Linux ARM64。
5. USB恢复/下载通道可用。
6. 1GbE网络可用。
7. HDMI显示输出可用。
8. PCIe NVMe识别、读写和压力测试通过。
9. 温升、功耗和长时间稳定性满足设计目标。

P1：
- Wi-Fi/BT模块
- MicroSD
- 第二个高速USB接口
- 风扇转速控制、RTC和扩展GPIO

## 4. 工程交付物

- KiCad工程、原理图、PCB和项目库
- 器件BOM及制造商料号
- 原理图网表与引脚核对表
- PCB叠层和阻抗计算
- ERC/DRC报告
- SI/PI与热设计记录
- Gerber、钻孔、坐标、装配图和钢网资料
- Linux启动镜像构建说明、设备树和测试记录
- 首板问题清单与修订记录

## 5. 当前阶段定义

当前为A0架构定义阶段。此阶段不允许发布可投板版本。必须先完成原厂资料收集、器件供应确认、Pinout审查、DDR方案和电源树评审。
