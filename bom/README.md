# A1 BOM规则

BOM按以下模块管理：
1. SoC：RK3568 FCBGA636L，19×19mm；LCSC候选C2938930（库存/价格需下单前复核）
2. PMIC/电源：RK809-5、VDD_CPU Buck、USB-C PD、5V/3V3电源
3. DDR：4GB LPDDR4X，完整料号待Rockchip支持清单确认
4. 存储：32GB eMMC、MicroSD卡座
5. 网络：RTL8211F-CG、MagJack
6. 无线：AP6275系列模块、天线座
7. 接口：HDMI、USB-A、USB-C、GPIO排针、UART
8. 保护：输入TVS、USB/HDMI低电容ESD、保险/限流器件

每项记录制造商、完整料号、封装、参数、LCSC编号（如有）、采购来源、库存核验日期和替代条件。未完成DDR兼容性核对的颗粒不得标记为冻结料。
