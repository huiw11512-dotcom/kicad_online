# RK809-5 PMIC page — A1 Rev1 implementation notes

Date: 2026-11-15  
Status: native editable KiCad page committed; not a fabrication release.

## 1. Selected device and package

- U3: Rockchip RK809-5.
- Package: QFN68, 7.0 × 7.0 mm, 0.35 mm lead pitch.
- Exposed pad: 5.49 × 5.49 mm nominal.
- Local candidate footprint: `A1_PMIC:RK809_QFN-68-1EP_7x7mm_P0.35mm_EP5.49x5.49mm`.
- Footprint contains 68 numbered perimeter lands plus EP pad 69. The source geometry matches the package dimensions in RK809 Datasheet Rev 2.5; the exact land pattern and stencil/thermal-via strategy still require assembly-house confirmation.

## 2. PMIC input distribution

| Pins | Name | A1 net | Decoupling |
|---|---|---|---|
| 4, 10, 11, 22, 24, 30, 54, 57, 66 | VCC1–VCC9 | VCC3V3_SYS | Local input bypass distributed as shown on the schematic |
| 45 | VCC_RTC | VCC3V3_SYS | Local bypass; same pre-PMIC 3.3V source |
| 44, 48 | VCC_1P8A/VCC_1P8D | VCC_1V8 | 1uF each |
| 33 | VCC_SPK_HP | PMIC_SPK_HP_5V | 1uH filter + 10uF/100nF |

VCC1–VCC9 and VCC_RTC are supplied from the pre-PMIC 3.3V system rail, generated by U6 TPS62132RGTT on A1_3V3_POWER.kicad_sch (5V_SYS to 3.3V, 3A). Do not connect these pins to 5V_SYS. VCC_RTC must be above 3.0V before VDC/PWRON initiates the sequence; VCC_SPK_HP is a separate filtered audio supply and remains on 5V_SYS.

## 3. Buck power stages

| Channel | Default RK809-5 setting | A1 implementation | State |
|---|---:|---|---|
| BUCK1 | 0.9V | 0.47uH, 2×47uF, output net VDD_LOGIC_0V9 | Voltage/load mapping to SoC pending |
| BUCK2 | 0.9V | 0.47uH, 2×47uF, output net VDD_GPU_0V9 | Voltage/load mapping to SoC pending |
| BUCK3 | 1.1V target | 0.47uH, 2×47uF, R1=37.4k RH/R2=100k RL | LPDDR4X VDD2 1.1V; Micron MT53E512M32D1ZW-046B WT:B 2GB x32 first-spin baseline; template/BIN validation pending |
| BUCK4 | 0.9V target, OFF | 0.47uH + 2×47uF stage populated; output VDD_NPU_0V9 | Hardware retained; OTP-default OFF |
| BUCK5 | 1.8V | 0.47uH, 2×47uF; supplies internal 1.8V PMIC rails | 1.8V default retained |

Rockchip's RK3568 guide specifies 0.47uH inductors with saturation current above 3.5A and DCR below 50mOhm (preferably below 20mOhm). It specifies more than 30uF output capacitance for BUCK1/2/3/4 and more than 33uF for BUCK5. The schematic uses 2×47uF nominal per active buck as a conservative starting point; effective capacitance under DC bias must be checked against the selected capacitor datasheet.

BUCK3 uses an external divider referenced to 0.8V. With R1=37.4kΩ (RH) and R2=100kΩ (RL), `VBUCK3 = 0.8 × (1 + 37.4/100) ≈ 1.099V`. This is the selected 1.1V VDD2 rail for the Rev1 Micron MT53E512M32D1ZW-046B WT:B (2GB, x32, single-die) first-spin baseline. The previously considered 4GB MT53E1G32D2FW-046 WT:C is a separate dual-die alternate and is not the current schematic baseline. The divider values are fixed for 1.1V; verify output tolerance, transient response and sequencing with the selected memory and confirmed Rockchip template/BIN before release.

## 4. LDO and switch channels

The RK809-5 OTP defaults from Datasheet Rev 2.5 are retained as the initial state:

| Output | Default | Startup sequence | A1 treatment |
|---|---:|---:|---|
| LDO1 | 0.6V OFF | OFF | NC |
| LDO2 | 0.9V | 1 | 1uF; output net reserved |
| LDO3 | 0.9V | 1 (about 200us after LDO2) | 1uF; output net reserved |
| LDO4 | 0.6V OFF | OFF | NC |
| LDO5 | 3.3V | 4 | 1uF; output net reserved |
| LDO6 | 3.3V | 2 | 1uF; output net reserved |
| LDO7 | 1.8V | 2 | 1uF; output net reserved |
| LDO8 | 1.8V | 2 | 1uF; output net reserved |
| LDO9 | 0.6V OFF | OFF | NC |
| SWOUT1 | 3.3V | 4 | VCC_3V3; 1uF local bypass |
| SWOUT2 | 3.3V | 4 | VCC3V3_SD for microSD card VDD; 1uF local bypass |

These are the RK809-5 OTP defaults, not the final SoC rail map. Connect these outputs to RK3568 power balls according to the Rockchip EVB power tree, then re-check all rail voltages and IO-bank assignments against the selected memory and pinmux.

**MicroSD supply rule:** SWOUT2 is the intended VCC3V3_SD source (sequence slot 4; 2.1A max, 100mΩ RDS(on) per RK3568 EVB User Guide Rev1.2). SD-page R57, a 0Ω link from VCC3V3_SYS to VCC3V3_SD, must be DNP; populating it bypasses SWOUT2.

## 5. Startup and control

- VDC divider: R9=100kΩ upper / R10=33kΩ lower from 5V_SYS gives approximately 1.24V, above the 0.55V startup threshold and close to Rockchip's recommended 1.2V. The R9/R10 BOM values have been corrected to match this divider.
- VCC_RTC must be above 3.0V before VDC or PWRON starts the sequence.
- After EXT_EN rises, VCC9 must already be above 3.0V within 1.5ms. A1 supplies VCC9 and VCC_RTC from the pre-existing 5V_SYS rail.
- EXT_EN drives the external VDD_CPU regulator enable.
- PWRON is active low with an internal 17k pull-up to VCC_RTC; SW1 must hold it low for more than 500ms to trigger power-on.
- SLEEP is held low through 100k for normal operation.
- RESETB is open drain and has the required 100nF capacitor; its pull-up is to VCC3V3_PMU (3.3V), matching RK3568 PMUIO.
- SCL/SDA/INT/RESETB/CLK32K are treated as open-drain signals and pulled up to VCC3V3_PMU (3.3V), matching RK3568 PMUIO.
- RTC crystal: 32.768kHz, CL=12.5pF candidate; two 22pF load capacitors follow the Rockchip guide's recommended value. Confirm the final crystal CL and parasitic capacitance.
- BATDIV, SNSP and SNSN are grounded because the fuel gauge is not used.

## 6. Explicitly unused functions

A1 Rev1 does not include the RK809 audio codec, headphone amplifier, microphone inputs, speaker output, or I2S/PDM audio. Pins 14–19 and 32–43 are marked NC, except VCC_SPK_HP which retains its filtered supply network per Rockchip's hardware guide. Fuel-gauge pins are grounded as specified above.

## 2026-11-16 IO pull-up voltage correction

R3/R4 (I2C0 PMIC bus), R5 (PMIC_INT_N), R6 (PMIC_RESETB_N), R7 (PMIC_CLK32K) now pull up to VCC3V3_PMU, **not** VCC_1V8. RK3568 I2C0 PMUIO and GPIO0_A3 are on 3.3V PMU banks in the selected IO-domain scheme. This follows the Rockchip EVB and Radxa RK3568 management circuit convention. Check the RK809 CLK32K output pull-up recommendation at component datasheet level before fabrication.
