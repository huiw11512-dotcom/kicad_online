# LPDDR4X DDR power rails — A1 Rev1 page 3

Status: native editable schematic page committed; not a fabrication release.

## Rail architecture

| Rail | Source | Voltage | Function |
|---|---|---:|---|
| VCC_DDR_1V1 | RK809-5 BUCK3 | 1.10V | LPDDR4X VDD2 and RK3568 DDRPHY_VDDQ |
| VCC0V6_DDR | SY8089AAAC buck | 0.60V | LPDDR4X VDDQ and RK3568 DDRPHY_VDDQL |
| VCC1V8_DDR | AP2112K-1.8TRG1 LDO | 1.80V | LPDDR4X VDD1 |

The Rockchip LPDDR4X reference circuit separates the 1.1V, 0.6V and 1.8V rails. The 0.6V rail is not generated by RK809 BUCK3. The reference schematic uses a dedicated SY8089-class buck for 0.6V and a separate 1.8V LDO.

## U4 — SY8089AAAC, 0.6V buck

- Input: VCC_3V3 from RK809 SWOUT1.
- EN: tied to VCC_3V3 (not left floating).
- LX: 2.2uH inductor L7.
- FB: directly tied to VCC0V6_DDR for 0.6V output (SY8089 reference = 0.6V).
- Input capacitor: 10uF.
- Output capacitors: 2×22uF + 100nF.
- Part: SY8089AAAC, SOT23-5, 2A continuous / 3A peak; LCSC C78988.
- L7: TDK SPM5030T-2R2M-HZ, 2.2uH, Isat 3.6A typ, DCR 21.23mOhm max. It exceeds the converter's 2A continuous rating.

## U5 — AP2112K-1.8TRG1, 1.8V LDO

- Input and EN: VCC3V3_PMU from RK809 LDO6.
- Output: VCC1V8_DDR.
- Input capacitor: 1uF; output capacitor: 4.7uF + 100nF.
- Part: AP2112K-1.8TRG1, SOT-25, 600mA minimum output capability; LCSC C176944.
- The upstream RK809 LDO6 VCC3V3_PMU rail is limited to 400mA. The total load shared by PMUIO1/2 and this DDR LDO must therefore be budgeted below 400mA with margin.

## Sequence intent

- PMIC BUCK5 / LDO6 stage 2 provide VCC_1V8 and VCC3V3_PMU.
- PMIC BUCK3 stage 3 provides VCC_DDR_1V1.
- PMIC SWOUT1 stage 4 enables VCC_3V3; SY8089 then starts VCC0V6_DDR.
- This ordering is intended to establish 1.8V, then 1.1V, then 0.6V. Confirm ramp order, maximum inter-rail delay, and power-down sequence against the selected LPDDR4X datasheet before release.

## Local decoupling

- Page 3 includes local bulk bypass for VCC_DDR_1V1, VCC0V6_DDR and VCC1V8_DDR.
- Additional 100nF and 1uF decoupling must be placed adjacent to the SoC DDR PHY balls and DRAM supply balls per the selected Rockchip DDR PCB template.
- Do not substitute the page-level capacitors for per-device DDR decoupling.

## Open gates

1. Confirm exact DRAM MPN, package, capacity and Rockchip DDR template/BIN pair.
2. Confirm VDD1/VDD2/VDDQ current and ramp requirements from that DRAM datasheet.
3. Verify AP2112K thermal rise and the combined current load on RK809 LDO6.
4. Verify SY8089 thermal rise at 0.6V maximum load and the selected inductor's saturation/current derating.
5. Complete KiCad ERC/netlist and PCB power-loop/decoupling placement review.

## DRAM integration update — 2026-11-16

The first-spin DRAM schematic uses Micron MT53E512M32D1ZW-046B WT:B (2GB, x32, single rank). U10 maps VDD1/VDD2/VDDQ to VCC1V8_DDR/VCC_DDR_1V1/VCC0V6_DDR respectively. R40 is 240Ω ±1% from ZQ0 to VDDQ. The Micron 200-ball footprint retains the vacant L/M row positions; the outer row center distance is 13.65mm. The exact Rockchip template/BIN pairing and final land-pattern review remain open.
